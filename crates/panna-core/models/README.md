# Text recognition models

`text-detection.rten` and `text-recognition.rten` are the pre-trained models of the
[ocrs](https://github.com/robertknight/ocrs) OCR engine by Robert Knight, from
[ocrs-models](https://github.com/robertknight/ocrs-models), unchanged. They were trained
on the [HierText](https://github.com/google-research-datasets/hiertext) dataset
(CC-BY-SA 4.0). Panna builds them into the app so text can be recognised offline.
